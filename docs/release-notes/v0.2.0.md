# v0.2.0 — 山大政管学院校友平台二期

本次发布在既有校友管理与数据大屏能力上，补齐批量导入导出、档案文件管理、敏感字段保护和缓存优化，并加固导入导出与文件链路的边界校验。

## 新增功能

- **数据导出**：管理员可将筛选后的校友数据导出为 Excel（`.xlsx`）或 CSV（`.csv`），并做公式注入防护。
- **批量导入**：管理员可通过 Excel 批量导入校友数据，按姓名、年级、班级、届数四字段去重，并给出带行号的错误反馈。
- **档案文件管理（MinIO）**：管理员可为校友上传、下载和删除学位档案与学籍档案，支持 PDF、Word、JPG、PNG，单文件上限 50MB。
- **敏感字段保护**：普通校友查看他人资料时，手机号、职务、通讯地址自动隐藏，采用 fail-closed 策略。
- **数据大屏增强**：新增地域和行业维度分析，交互与视觉全面升级。
- **Redis 缓存优化**：校友总数主动缓存配合导出版本号缓存，列表 `COUNT` 与导出全表扫描查询明显提速。

## 安全加固

- 导出公式注入防护：转义以 `=`、`+`、`-`、`@` 开头的单元格。
- 文件路径穿越防护。
- 导入文件魔数校验，限制 20MB 与 5000 行。
- 文件类型白名单校验。

## 基础设施

- 新增 `alumni_files` 表存储文件元数据，Compose 增加 MinIO 对象存储服务。
- 新增 Redis 缓存层（计数缓存与导出结果缓存）。
- 校友文件仓库改用 GORM Gen 查询助手实现。

## 数据库变化

- 新增 `002_seed_test_user.sql`：写入测试校友与测试账号数据，便于本地联调。
- 新增 `003_add_alumni_files.sql`：创建 `alumni_files` 表。

## 升级说明

- 在旧库上按顺序执行新增迁移即可，无需重建数据卷。
- 需要文件管理能力时，须同时配置 `MINIO_*` 与 `STORAGE_*` 环境变量并启动 MinIO 服务。
