# 发布说明

本目录存放手工撰写的发布说明。`.github/workflows/release.yml` 在推送 `vX.Y.Z` 标签时，会按标签名查找同名文件：

- 存在 `docs/release-notes/vX.Y.Z.md`：用该文件作为 Release 正文；若首行是 `# 标题`，则用该标题作为 Release 标题。
- 不存在：回退到 GitHub 自动生成的 release notes。

## 已发布版本

- `v0.1.0`（2026-06-01，一期 MVP）：登录认证、校友档案管理、校友查询、数据大屏、管理员账号管理。
- `v0.2.0`（2026-06-07，二期）：批量导入导出、MinIO 档案文件、敏感字段保护、大屏增强、Redis 缓存。
- `v0.3.0`（2026-06-28，三期）：验证码登录、接口限流与 CORS、地域地图大屏、短信与邮件能力。
- `v0.3.1`（2026-06-28，三期修复）：MinIO 预签名 URL 改为经 nginx 同源代理。
- `v0.4.0`（2026-10-15，四期）：管理员精细化授权、操作审计、院史共编、Nightly 与 Release 流程。
- `v0.5.0`（2026-10-17，五期）：院史删除申请与交叉审核、Markdown 编辑器与六级目录、Swagger 接口文档、通用档案查询限管理员、导入与依赖安全加固、CI 依赖升级到 node24 与 runner 固定为 Ubuntu 26.04。
- `v0.5.1`（2026-10-22，五期修复）：操作历史列表 1038 崩溃与本地时区展示修复、导出导入闭环（所属领域列、CSV 回灌、上限 20000）、Web 入口 HTML 缓存策略修复、Go 工具链与 follow-redirects 高危依赖升级、Nightly 误判自动重跑。

## 约定

- 文件名与标签完全一致，例如 `v0.4.0.md` 对应标签 `v0.4.0`。
- 首行建议写 `# v0.4.0 — 山大政管学院校友平台四期`，与该标签已有发布的标题风格保持一致。
- 正文使用中文，按 `## 新增功能`、`## 优化与修复`、`## 数据库变化`、`## 升级说明` 等小节组织；数据库变更写清新增迁移编号，无迁移时明确说明。
- 新增版本发布说明后，同步在上方清单中登记。
- 不要写入真实个人信息、密码、Token 或生产配置。
