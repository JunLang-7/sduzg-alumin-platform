# v0.4.0 — 山大政管学院校友平台四期

本次发布在既有校友管理、校友查询与数据大屏能力上，补齐了管理员精细化授权、操作审计与院史共编三项核心能力，并把测试、持续集成与发布流程补成完整链路。

## 版本亮点

- 新增“角色 + 数据域 + 功能权限”授权体系，支持按本科生、学术学位研究生、MPA 三类数据域分配管理员访问范围。
- 新增操作历史与字段变更审计，可查看校友资料新增、修改、删除、导入、导出及文件操作记录。
- 新增院史共编模块，支持校友阅读词条、投稿、上传资料，以及管理员按数据域审核发布。
- 新增 Nightly 与 Release 自动化：定时全量验证并产出可下载构建产物，推送版本标签后自动校验、构建、发布，并保留人工放行。

## 新增功能

### 管理员权限管理

- 超级管理员可查看管理员详情并配置数据域和功能权限。
- 校友列表、详情、数据大屏、导入导出和档案文件均接入统一授权校验。
- 无权访问的敏感字段、跨域数据和文件会在服务端拦截，避免仅依赖前端菜单控制。
- 管理员权限调整后，可在后续请求中即时生效。

### 操作历史与审计

- 管理后台新增“操作历史”页面，支持按操作类型、操作者、目标和时间查看记录。
- 新增操作详情抽屉，展示单次操作及字段变更内容。
- 校友详情页增加相关操作历史入口。
- 审计信息避免记录密码、预签名地址等敏感内容。

### 院史共编

- 登录用户可浏览和检索已发布院史词条。
- 校友可创建投稿、补充资料、上传图片或 PDF，并查看投稿状态。
- 管理员可在授权数据域内审核投稿，支持通过、退回补充和驳回。
- 审核通过后生成正式词条及版本记录，投稿附件同步进入对应状态。
- 细化协作词条流程，投稿与编辑表单、附件编辑体验得到调整。
- 投稿正文修改后预览即时刷新，不再显示旧内容。

## 优化与修复

- 修复表格导入时解析失败相互影响的问题，单个文件失败不会干扰其他处理流程。
- 增强管理员账号与手机号校验。
- 修复院史数据库迁移遗漏及管理员访问问题。
- 院史词条标题不再附带 `v1`、`v2` 等版本标识，版本信息与标题分开展示。
- 修复院史投稿正文修改后预览仍显示旧内容的问题。
- 恢复操作详情字段表格样式。
- 恢复 MinIO 镜像拉取，并保持既有数据卷兼容。
- 加固 `migrate` 服务跨机器启动兼容，修复旧卷迁移记录误标导致的升级中断。
- 优化登录页、校友列表、校友详情、数据大屏和管理员页面的交互与视觉样式。
- 清理前端 React Hook 依赖警告。
- 升级并锁定前后端依赖，修复已知依赖风险；收窄日常自动升级范围。

## 工程质量与发布

- 新增统一的 `format`、`lint`、`test`、`build` 和 `e2e` 检查流程。
- CI 覆盖提交信息、Issue 关联、后端测试、前端测试、数据库迁移、依赖安全、镜像构建和健康检查。
- 新增 Chromium 端到端测试，覆盖登录、权限、校友管理、文件操作和院史投稿审核主流程。
- 新增 Nightly：每天 02:00（北京时间）运行完整门禁，并产出 API 二进制、Web 静态包、`BUILD_INFO.txt` 与 `SHA256SUMS`，保留 14 天；API 二进制先通过存活与就绪检查。
- 新增 Release：推送 `vX.Y.Z` 标签触发，先校验标签格式与 `main` 归属，再运行完整门禁与升级路径门禁，然后构建产物并校验校验和与前端静态包可服务，最后创建 GitHub Release。
- 新增升级路径门禁：用上一个发布标签的迁移集初始化数据库模拟旧库，执行生产同款 `migrate.sh`，断言迁移记录齐全、既有数据未丢失、数据域回填无空值与孤儿行、中文名称无乱码，并重复执行验证幂等。
- 发布使用 `release` environment，配置 required reviewers 后需要人工放行才会对外发布。
- GitHub Actions 运行时升级到 Node 24，并收紧依赖自动升级范围。

## 数据库变化

新增 `006`—`009` 号迁移，主要包括：

- 管理员数据域与功能权限表。
- 校友档案数据域字段及历史数据回填。
- 院史词条、词条版本、校友投稿和投稿附件表。
- 数据库迁移执行记录表及增量迁移脚本。

## 升级说明

- 旧数据卷不需要重建：`docker compose` 启动时由 `migrate` 服务执行 `server/scripts/migrate.sh`，增量升级到当前迁移集；脚本会修复“迁移已标记但目标表不存在”的旧记录。
- 升级路径已在 CI 中以 `v0.3.1` 的库结构完整验证（含数据域回填、中文编码修复与幂等）。
- 生产部署请更换默认超级管理员密码与 JWT secret，并为 `release` environment 配置 required reviewers。

## 已知限制与后续优化

院史共编的主要业务流程已经打通，仍在体验优化和细节完善阶段：

1. 完善管理员编辑词条的权限控制，明确不同管理员的数据域和操作边界。
2. 调整投稿及编辑表单的输入逻辑，重点优化“编辑章节”字段的选择、填写和校验方式。
3. 明确“创建词条”和“更新词条”两类操作；在已有词条页面增加“更改词条”按钮，避免与新建投稿入口混淆。
4. 去除页面中不必要的辅助小字，精简界面信息层级。
5. 优化词条搜索功能，包括关键词匹配、结果反馈、无结果状态和搜索重置体验。
6. 调整词条目录的布局与视觉样式，提升目录层级、选中状态和正文区域的可读性。
7. 优化“参考资料”一行的展示文案与排版，使资料来源信息更加清晰。
