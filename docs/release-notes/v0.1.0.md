# v0.1.0 — 山大政管学院校友平台一期 MVP 发布

一期 MPA 试点的首个可部署版本，打通账号登录、校友档案管理、校友查询、个人资料维护、数据大屏和管理员账号管理主链路。

## 新增功能

- **登录与权限**：支持游客、校友、管理员、超级管理员四类角色，使用 JWT 访问令牌认证，提供登出与修改密码能力。
- **校友信息管理**：管理员可对 MPA 校友数据进行新增、修改、查询和软删除，支持分页与多维搜索筛选。
- **校友信息查询**：登录校友可查看 MPA 校友列表及详情。
- **个人信息维护**：校友可维护本人的工作单位、职务、通讯地址和手机号。
- **数据大屏**：管理员可查看校友总人数，以及年级、班级、届数、性别、专业、培养方式等维度分布。
- **管理员管理**：超级管理员可创建、查看和删除管理员账号。
- **基础安全**：密码哈希存储、登录失败次数记录与账号锁定、操作日志审计、数据软删除。
- **基础运维**：提供 `/api/v1/health/live` 与 `/api/v1/health/ready` 健康检查，Docker Compose 可一键启动 MySQL、Redis、API 与 Web。

## 技术栈

- 后端：Go 1.26 + Gin + GORM + MySQL 8.0 + Redis + JWT
- 前端：React 18 + Vite + TypeScript + Ant Design + Zustand + ECharts
- 编排：Docker Compose（MySQL + Redis + API + Web）

## 数据库变化

- 新增 `001_init_schema.sql`：创建 `sdu_alumni_db`，以及 `users`、`alumni_profiles`、`operation_logs` 三张表和相关索引。

## 升级说明

- 首个发布版本，从空库初始化即可完成部署。
- 迁移脚本会写入默认超级管理员账号 `admin`，仅用于启动和开发场景；生产部署必须更换默认密码与 JWT secret。
