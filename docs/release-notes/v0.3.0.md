# v0.3.0 — 山大政管学院校友平台三期

本次发布补充短信与邮箱验证码登录、接口限流与 CORS 配置、地域地图大屏，并把文件上传改为客户端直传。

## 新增功能

- **验证码登录与强制密码设置**：新增短信/邮箱验证码登录流程，注册用户同步真实姓名和邮箱字段，并引导用户完成密码设置。
- **短信服务升级**：短信发送服务切换为腾讯云实现，补充 SMS 配置示例，便于生产环境接入。
- **邮件验证码**：接入 SMTP 邮件验证码发送能力，支持以邮箱作为账号安全验证通道。
- **管理员导出模板**：管理员校友管理页面新增导出模板功能，降低批量数据维护门槛。
- **数据大屏地图增强**：新增可交互的校友区域地图，覆盖全国、省、市及山东城市地图资源。
- **数据大屏图表优化**：优化毕业率图表与地域行业分布加载性能，提升大屏浏览体验。
- **文件直传**：引入 MinIO Presigned URL，客户端可直传文件，减轻 API 转发压力。
- **用户区域信息**：页面右上角显示真实姓名与中文角色标签。

## 安全加固

- 新增接口限流能力，支持内存与 Redis 两种限流器，覆盖登录等敏感接口。
- 新增可配置 CORS 中间件，按环境控制跨域访问边界。
- 收窄校友端菜单权限，避免普通校友看到不应访问的入口。
- 导入去重逻辑增加手机号字段，降低重复档案写入风险。

## 基础设施

- 统一 Docker Compose 环境变量管理，移除硬编码密码。
- 新增登录尝试、验证码等仓储与服务支撑能力。
- 新增 `users.email` 相关迁移、模型和查询代码。
- 补充限流边界测试脚本与多组后端单元测试。

## 数据库变化

- 新增 `004_add_user_email.sql`：`users` 与 `alumni_profiles` 增加 `email` 列，`users.email` 加唯一索引。
- 新增 `005_add_indexes.sql`：`users.mobile` 加唯一索引，`alumni_profiles.email` 加查询索引。

## 升级说明

- 在旧库上按顺序执行新增迁移即可，无需重建数据卷。
- 启用验证码登录前需配置 `SMS_TENCENT_*` 与 `EMAIL_*`；生产环境按需收紧 `CORS_*` 与 `RATE_LIMIT_*`。
