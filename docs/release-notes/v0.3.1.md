# v0.3.1 — 山大政管学院校友平台三期修复

本次为三期修复版本，集中解决 Docker 环境下 MinIO 预签名 URL 无法直接用于浏览器上传下载的问题，改为经 nginx 同源代理转发。

## 优化与修复

- **MinIO 文件上传修复**：预签名 URL 改用 nginx 代理方式，解决 Docker 内部 hostname 浏览器无法解析导致的上传失败。
- **签名修复**：nginx 转发时设置正确的 `Host` 头，使 AWS V4 签名校验通过。
- **同源路径修复**：前端上传、下载和预览统一使用同源路径 `toSameOriginStorageURL`，不再依赖具体部署 IP、域名或 CORS 配置。

## 基础设施

- 新增 `STORAGE_PUBLIC_ENDPOINT` 配置项，支持替换预签名 URL 中的公开访问地址。
- nginx 新增 `/sdu-alumni-files/` 到 MinIO 的代理，浏览器文件操作走同源路径，并设置 `client_max_body_size 60m`，避免大文件上传被拦截。
- Vite dev server 新增 `/sdu-alumni-files` 到 MinIO 的代理，本地开发可直接调试文件链路。

## 数据库变化

- 本版本未新增或修改数据库迁移，仍为 `001`—`005`。

## 升级说明

- 纯修复版本，更新镜像后重新部署即可。
- 若 MinIO 的对外地址与内部地址不同，需要配置 `STORAGE_PUBLIC_ENDPOINT` 指向浏览器可访问的地址。
