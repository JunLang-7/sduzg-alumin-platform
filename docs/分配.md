```text
校友提交修订
→ 系统识别词条分类、是否有图片、是否涉及人物/敏感内容
→ 匹配审核组
→ 从该组内筛选可审核管理员
→ 按负载最少 + 轮询规则自动指派
→ 超时自动催办或升级转派
```

自动规则可以这样定：

1. 先按词条分类分组  
   - “学院沿革、重大事件” → 院史办公室  
   - “MPA 教育、课程活动” → MPA 教育中心  
   - “校友人物、口述史” → 校友工作组  
   - “图片、扫描件” → 资料管理员参与复审  

2. 再筛选具体审核人  
   系统排除：
   - 投稿人本人，禁止自审；
   - 已禁用、请假或不在线的管理员；
   - 已达到待审上限的人；
   - 与投稿人存在需回避关系的人。

3. 在可选人中自动选人  
   推荐优先级：

   ```text
   该分类负责人
   → 当前待审数量最少者
   → 最久未被分配者（轮询）
   ```

   例如“MPA 教育”有 A、B、C 三位审核员，待审数分别为 4、2、2，则分给 B、C 中上一次更早收到任务的人。

4. 风险内容自动升级  
   以下内容不直接普通审核：
   - 含人物评价、争议叙述；
   - 含图片、扫描件、肖像；
   - 词条被举报过；
   - 修改历史超过一定次数。

   这些进入“双人审核”：初审通过后，系统自动再分给另一位不重复的审核员复审。

5. 超时自动处理  
   - 24 小时未处理：提醒当前审核人；
   - 72 小时未处理：自动转给组长；
   - 组长仍超时：进入超级管理员“异常待分配”队列。

表字段可增加：

```text
review_group_id       审核组
reviewer_id           当前审核人
assigned_at           分配时间
assignment_mode       auto / manual / escalated
review_deadline_at    审核截止时间
risk_level            normal / high
```
