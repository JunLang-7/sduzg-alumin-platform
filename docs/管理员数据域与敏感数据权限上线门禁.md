# 管理员数据域与敏感数据权限上线门禁

本清单对应 Issue #44，用于发布前确认“角色 + 数据域 + 功能权限”模型没有旁路。

## 数据域与账号矩阵

| 测试主体 | 数据域 | 敏感数据 | 档案文件 | 预期 |
| --- | --- | --- | --- | --- |
| 超级管理员 | 全部 | 全部 | 全部 | 可跨全部数据域管理 |
| 本科管理员 | 本科生 | 可选 | 可选 | 仅能访问本科生校友 |
| 学术研究生管理员 | 学术学位研究生 | 无 | 无 | 仅能访问本域，敏感字段为空 |
| MPA 管理员 | MPA | 可选 | 可选 | 仅能访问 MPA 校友 |
| 多域管理员 | 多个显式分配域 | 可选 | 可选 | 仅能访问分配域并可按领域筛选 |
| 无 scope/禁用管理员/普通校友 | 无或不适用 | 不适用 | 不适用 | 管理员入口拒绝；校友保留本人完整、他人脱敏规则 |

## 自动化验证

常规检查：

```bash
cd server && go test ./...
cd web && npm run build
docker compose up -d --build
```

真实 MySQL/Redis 门禁检查（测试均使用事务回滚或隔离 Redis DB，不保留测试数据）：

```bash
cd server
TEST_MYSQL_DSN='用户名:密码@tcp(127.0.0.1:3307)/sdu_alumni_db?charset=utf8mb4&parseTime=true&loc=Local' \
TEST_REDIS_ADDR='127.0.0.1:6379' \
TEST_REDIS_PASSWORD='对应 Redis 密码' \
go test ./internal/service ./internal/repository ./internal/cache -count=1
```

`TestPermissionMatrixAcrossBusinessEntrypoints` 覆盖三个数据域的真实库数据，断言：

1. 单域管理员的列表和分页总数只包含本域，跨域筛选返回权限拒绝。
2. 跨域详情和写入返回资源不存在，避免 ID 枚举。
3. 无敏感权限时列表与 CSV 导出不包含手机号和工作单位；带敏感权限时可读取本域敏感字段。
4. 导出审计只记录数据域、数量和是否包含敏感字段，不包含校友原值。
5. 大屏分布仅统计本域；无 scope 管理员被拒绝。

已有仓储、缓存、文件和授权上下文测试共同覆盖数据域 SQL 过滤、导出缓存键隔离、档案文件授权以及授权修改后下一请求生效。

## 发布前人工抽查

1. 分别使用本科、学术研究生、MPA 管理员登录，检查列表、详情、创建、更新、删除、导入、导出和大屏。
2. 使用无敏感权限账号确认页面显示“无权限查看”，不会将脱敏值误显示为“未填”；地域模块不得根据空敏感字段生成统计。
3. 使用无档案权限账号确认文件列表、上传、下载、删除均被拒绝。
4. 在超级管理员页面调整一个管理员的数据域或功能权限，不重新登录，下一请求应立即反映最新授权。
5. 检查 `operation_logs`：授权变更、导入、导出、档案操作均存在，且详情不含密码、敏感原值和预签名 URL。
