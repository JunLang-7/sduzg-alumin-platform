# 平台使用说明

本说明面向使用“政管全球校友数字化平台和院史在线平台”的三类账号：校友、管理员、超级管理员。内容按功能模块组织，每个模块说明入口、可执行操作和限制条件。

## 1. 角色与可用范围

| 角色           | 可用菜单与功能                                                                         |
| -------------- | -------------------------------------------------------------------------------------- |
| 游客（未登录） | 只能浏览平台首页；点击“校友服务”“院史共编”会跳转到登录页，看不到任何校友档案与院史内容 |
| 校友           | 用户中心（我的资料、绑定联系方式、修改密码）、院史共编（阅读词条、投稿、我的投稿）     |
| 管理员         | 校友服务、数据大屏、校友管理、操作历史、院史待审、院史共编                             |
| 超级管理员     | 管理员的全部功能，另加管理员管理                                                       |

说明：

- 校友端不显示“校友服务”菜单，校友目录按管理员的数据域开放；用校友账号直接访问管理员页面会跳转到 403 页面。
- 前端隐藏菜单只是界面表现，服务端同样会校验角色、数据域和功能权限，越权请求会被拒绝。

## 2. 数据域与功能权限（管理员）

管理员只能在被授权的培养类别内查看和操作校友数据，超级管理员可访问全部培养类别。

| 数据域            | 说明                       |
| ----------------- | -------------------------- |
| 本科生            | 本科校友档案               |
| 学术学位研究生    | 学术学位研究生校友档案     |
| MPA专业学位研究生 | MPA 专业学位研究生校友档案 |

功能权限有两项，由超级管理员逐账号授权：

| 权限           | 影响                                               |
| -------------- | -------------------------------------------------- |
| 可查看敏感数据 | 决定手机号、邮箱、工作单位、职务、通讯地址是否可见 |
| 可管理档案文件 | 决定学位档案与学籍档案的上传、下载、删除是否可用   |

没有“可查看敏感数据”权限时：

- 校友列表不显示“工作单位”“职务”列，关键词搜索的提示文字也不包含单位；
- 校友详情页中敏感字段显示 `***`；
- 导出的文件不包含敏感字段，操作历史详情同样不展示敏感原值。

没有“可管理档案文件”权限时，档案文件的列表、上传、下载、删除都会被服务端拒绝。

管理员的数据域或功能权限被调整后，不需要重新登录，下一次请求即按新权限生效。

## 3. 登录与账号

### 3.1 登录方式

登录页提供三个页签：

| 页签           | 输入项                                    |
| -------------- | ----------------------------------------- |
| 密码登录       | 用户名（手机号、邮箱或账号）与密码        |
| 短信验证码登录 | 手机号与 6 位数字验证码，先点“获取验证码” |
| 邮件验证码登录 | 邮箱与 6 位数字验证码，先点“获取验证码”   |

使用验证码登录时：

- 手机号或邮箱必须与校友档案中的联系方式一致，否则提示无法匹配（不会透露账号是否存在）；
- 如果该手机号或邮箱还没有对应账号，系统会先弹出“请设置您的登录密码”，设置成功后即完成账号开通并登录；
- 若账号已被禁用，无法登录。

密码规则：至少 8 位，且同时包含字母和数字。同一标识在 5 分钟内连续登录失败 5 次会被临时锁定，请稍后再试。

### 3.2 修改密码与退出登录

点击右上角用户区域，可执行：

- 修改密码：填写原密码、新密码、确认新密码；
- 退出登录：返回登录页。

平台目前没有自助找回密码入口。忘记密码时，请联系超级管理员重置。

## 4. 校友端：用户中心

### 4.1 我的资料

可自行维护的字段为工作单位、职务、手机号、通讯地址，点击“保存”提交。

姓名、年级、班级、届数、专业、培养方式、辅导员、导师、行业、培养类别等档案信息由管理员维护。本人修改资料同样会计入操作历史。

### 4.2 绑定联系方式

在“联系方式”区域点击“绑定”，弹窗中填写尚未绑定的手机号或邮箱，并输入验证码完成绑定。已经绑定的联系方式以掩码显示（例如 `138****1111`）；手机号与邮箱都已绑定时，弹窗只做展示。

绑定的手机号和邮箱同时用于验证码登录，变更会同步更新到校友档案。

## 5. 院史共编

校友、管理员和超级管理员都可以进入“院史共编”，游客不可访问。

### 5.1 阅读与检索

- 左侧为“院史目录”，移动端通过顶部“目录”按钮打开；
- 顶部搜索框按“正式词条的标题、简介或正文”检索，回车或点击“搜索”执行，搜索后会在正文上方提示“找到 N 个词条”或“未找到与…相关的正式词条”；
- 正文区展示“正式词条”标签、标题、简介、最近更新日期、正文和“参考资料”；
- 右侧目录可点击跳转到对应小节。

### 5.2 新建词条、补充修改与编辑词条

- 校友和管理员都可以点击“新建词条”提交新词条；
- 校友在已发布词条上可以点击“补充修改”，提交针对该词条的修改稿；
- 管理员在已发布词条上可以点击“编辑词条”，直接更新正式内容。

编辑表单字段：

| 字段                | 说明                                                 |
| ------------------- | ---------------------------------------------------- |
| 词条标题            | 必填                                                 |
| 正文                | 必填，正文中可自行分节                               |
| 资料来源            | 必填，用于说明资料出处                               |
| 词条简介 / 修改说明 | 新建时可填写简介；修改已有词条时填写修改说明         |
| 所属数据域          | 管理员投稿时必填，可选项来自该管理员可管理的培养类别 |
| 附件                | 可选，见下方规则                                     |

附件规则：

- 类型支持 JPG、PNG、WebP、PDF；
- 单个文件不超过 10 MB，每次投稿最多 6 个；
- 添加附件后必须勾选“我确认附件来源真实且有权提交”；
- 已上传的附件可以“预览”“编辑资料”“移除”。

提交方式：

- “存为草稿”（新建时）或“保存草稿”（编辑未提交的投稿时）先保存不提交；
- “提交审核”把投稿送入审核流程，审核通过后才会写入正式词条；
- 管理员直接编辑正式词条时使用“保存更改”，不进入审核流程。

### 5.3 我的投稿

右侧“我的投稿”列出本人提交的投稿，点击条目打开“投稿详情”，其中包含标题、状态、正文预览（点击“查看详情”查看全文）、资料来源、审核意见和附件列表（可“预览”）。

投稿状态：

| 状态   | 含义                   | 可执行操作                     |
| ------ | ---------------------- | ------------------------------ |
| 草稿   | 已保存但未提交         | 编辑投稿、删除草稿             |
| 审核中 | 已提交，等待管理员审核 | 编辑投稿（审核以最新内容为准） |
| 已退回 | 管理员要求补充         | 编辑投稿后重新提交             |
| 已通过 | 已写入正式词条         | 仅查看                         |
| 已驳回 | 审核未通过             | 仅查看                         |

管理员和超级管理员也可以在“院史共编”中投稿，投稿同样出现在自己的“我的投稿”中。

### 5.4 院史待审（管理员）

入口为管理菜单“院史待审”，列表只展示当前管理员有权限的培养类别下的待审投稿，点击“审核”进入详情。

- 详情展示词条正文、附件（可下载）与投稿信息；
- 处理方式有三种：“通过”“退回补充”“驳回”；
- 通过时会提示“通过后将更新正式词条”，确认后内容写入正式词条并生成版本记录，附件状态同步变为已通过；
- 退回和驳回需要填写处理说明，退回的投稿可由投稿人补充后重新提交；
- 处理完成后提示“处理成功”，列表自动刷新。

### 5.5 词条删除申请与审核（管理员）

校友没有删除入口，也不能调用删除相关接口。

- 管理员在“院史共编”页对本人数据域内的已发布词条点击“申请删除词条”，填写删除原因（必填，最多 2000 字）后提交；
- 申请待审期间词条继续展示，按钮变为“删除申请待审核”并禁用，不能重复申请；
- “我的删除申请”栏跟踪每条申请的状态与审核意见，驳回后可以再次申请；
- 审核入口在“院史待审”页的“词条删除申请”表：普通管理员只看到同数据域其他管理员的待审申请，不能同意或驳回自己的申请；
- 处理方式：“同意”执行软删除，词条不再展示，历史投稿、版本和附件记录保留；“驳回”必须填写审核意见（最多 2000 字）；
- 超级管理员可申请删除全部词条、自行审核申请，并保留“删除词条”直接删除入口；普通管理员没有直接删除入口。

接口方法、路径与权限见[接口文档](api.md#院史共编)。

## 6. 校友服务与档案文件（管理员）

### 6.1 校友列表

菜单“校友服务”按个人信息和学籍信息检索校友档案：

- 筛选条件：关键词、年级、班级、届数、培养层次、培养类别、专业、培养方式、行业；
- 年级、班级、届数、专业、培养方式、培养层次和培养类别由**同一段学籍**满足；例如“2015 级本科”不会命中“2015 级硕士”；
- 关键词在有敏感数据权限时匹配“姓名、单位、导师”，无权限时只匹配“姓名、导师”；
- 提供“查询”与“重置”，结果分页展示；列表按人去重，同一校友的多段学籍以标签形式一并显示。

### 6.2 校友详情

点击列表中的“查看”进入校友详情，页面包含三部分：

1. 校友档案：姓名、性别、手机号、邮箱、行业、工作单位、职务、通讯地址；无敏感数据权限的字段显示 `***`；
2. 学籍信息：每一段可访问学籍单独成卡，展示培养层次、培养类别、年级、班级、届数、专业、培养方式、辅导员、导师和管理员备注，并分别列出该段的学位档案与学籍档案；
3. 操作历史：定位到个人共享信息或具体学籍的字段变化。

查看页是只读的，不提供添加、编辑、上传或移除入口；所有修改从“校友管理”列表的“编辑”进入。看不到的学籍不会以数量、文件名或筛选选项出现。

### 6.3 档案文件

每个学籍段分别维护“学位档案”和“学籍档案”：

- 在“编辑”弹窗的“学籍与档案”分区上传；上传后先进入本次编辑的草稿，点击“保存全部修改”后才成为正式附件；
- 取消、关闭或按 Escape 退出编辑不会保存草稿，也不影响已有正式附件；本次上传的草稿会被清理；
- 正式附件的“移除”同样先标记为“待移除”，保存成功后才删除；取消编辑不会删除；
- 查看页可以下载正式附件；草稿不可下载；
- 上传、下载和移除需要“可管理档案文件”权限。

| 项目         | 限制                              |
| ------------ | --------------------------------- |
| 文件类型     | PDF、Word（.doc/.docx）、JPG、PNG |
| 单个文件大小 | 不超过 50 MB                      |

## 7. 校友管理（管理员）

菜单“校友管理”用于维护授权范围内的个人主档案与多段学籍。个人信息一人一份，账号绑定不变；每段学籍独立维护培养信息、管理数据域、内部备注和档案文件。

### 7.1 检索与分页

筛选条件：关键词（“姓名、单位、导师”）、年级、班级、届数、培养层次、培养类别、行业，提供“查询”与“重置”；表格支持分页与每页条数切换。

列表列包含姓名、学籍摘要、行业与操作；有敏感数据权限时额外显示“工作单位”“手机号”列。学籍摘要会显示每段的年级、培养层次、培养类别和专业。每行的操作为“查看”“编辑”“删除”。

### 7.2 新增与编辑

点击“新增校友”打开分区表单：

- “个人信息”：姓名必填；性别、行业可选；有敏感数据权限时还会显示手机号、邮箱、工作单位、职务、通讯地址；
- “学籍与档案”：至少填写一段学籍。每段必填培养类别、培养层次（本科/硕士/博士）和年级；班级、届数、专业、培养方式、辅导员、导师、管理员备注可选；
- 点击“添加一段学籍”可继续添加本科、硕士、博士或同层次的多段学籍；本次新增的学籍可“移除本次新增”，已保存学籍不会在表单里被删除；
- 单域管理员的培养类别固定为唯一授权域；已有学籍的培养类别不能通过编辑迁移；
- “管理员备注”只展示给能访问该段学籍的管理员。

“编辑”同样分为“个人信息”“学籍与档案”两个区：

- 修改一次联系方式、行业或任职信息，会同步更新该校友的全部学籍；
- 修改某段的年级、专业、导师等不会影响其他段；
- 点击“保存全部修改”时，个人信息、提交的学籍、文件草稿和移除操作在同一事务内提交；任一失败不会部分更新，也不产生成功日志；
- 取消、关闭、Escape、校验失败或服务失败后，原个人、学籍和正式文件保持不变；
- 如果另一位管理员刚保存过该校友，提交时会提示保存冲突，请重新加载最新数据核对后再保存。

“删除”需要二次确认，且仅对只有一段学籍的校友开放；多段学籍的整人删除语义尚未定义，列表会禁用删除并由服务端返回冲突，避免误删隐藏学籍或共享身份。

### 7.3 批量导入

1. 点击“导出模板”下载导入模板（`alumni_import_template.xlsx`）；
2. 数据表仅含表头和第 2 行空白行，请从第 2 行开始填写；空白行会被忽略。示例数据与填写规则见「填写说明」工作表；
3. 一行代表一段学籍。同一文件中姓名相同且手机号相同（无手机号时邮箱相同）的多行会合并为同一校友的多段学籍；缺少手机号和邮箱的行各自建档；
4. “培养层次”填写本科、硕士或博士（也可填编码）；“所属领域”可填写编码、显示名称或数字 ID；
5. 在“导入目标培养类别”下拉框选择本次导入的目标培养类别（只有单一培养类别权限的管理员无需选择）；选择后模板中的“所属领域”列会被忽略；
6. 点击“导入 Excel”，选择 `.xlsx` 或 `.csv` 文件。

当前模板 17 列：

| 列                                                                                                                       | 说明                                     |
| ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------- |
| 姓名、培养层次、年级、班级、届数、辅导员、导师、专业、培养方式、行业、工作单位、职务、通讯地址、性别、手机号、邮箱、所属领域 | 一行一段学籍；姓名、培养层次、年级必填   |

历史 15 列（无培养层次/所属领域）与 16 列（含所属领域）模板仍可导入：本科生域自动推断为本科、MPA 域推断为硕士；学术学位研究生无法区分硕/博，必须改用当前模板明确填写培养层次。

导入限制：

- 支持 `.xlsx` 与 `.csv`，文件不超过 20 MB；单次最多导入 20000 条数据；
- 按“姓名 + 手机号 + 数据域 + 年级 + 班级 + 届数”去重；库内重复和同文件重复均计为行错误，不覆盖更新；
- 导入不会凭姓名或手机号把新行自动挂接到数据库里已有的校友身份，需要添加学籍请编辑既有校友；
- 已停用数据域不能回灌，对应行会报“所属领域已停用”；
- 无“可查看敏感数据”权限时不能导入含手机号、邮箱、工作单位、职务、通讯地址的行；
- 导出的 CSV / XLSX 均可直接回灌；导出时为防公式注入加的 `'` 前缀会在导入时自动还原；
- 只有表头或全部空白行的文件会被拒绝，并提示“文件里没有可导入的数据行”；
- 导入完成后弹出“导入结果”，显示解析条数、成功条数，以及失败记录的“行号、姓名、错误原因”。

### 7.4 导出数据

点击“导出”，在下拉菜单中选择导出格式：

| 格式  | 文件                 |
| ----- | -------------------- |
| Excel | `alumni_export.xlsx` |
| CSV   | `alumni_export.csv`  |

导出平铺为一行一段有权限且符合筛选的学籍，输出 17 列（含“培养层次”和“所属领域”）。同一校友有多段学籍时个人信息重复填充，不会丢失或串段；没有权限的学籍不会出现在导出里。导出内容按当前筛选条件生成，可直接作为导入文件回灌（只新增、不更新）。没有“可查看敏感数据”权限时，导出文件不含手机号、邮箱、工作单位、职务、通讯地址；这类脱敏文件不要用于回灌。已停用数据域的历史学籍可以导出，但回灌会被拒绝。导出操作与范围会记录到操作历史。

## 8. 数据大屏（管理员）

菜单“数据大屏”展示当前管理员可管理范围内的统计结果，包含：

- 指标卡：校友总数、已开通账号、账号开通率、资料完整度、手机号完整率、单位完整率、导师完整率；
- 多维分布主图：可切换年级、班级、毕业率、性别、专业、培养方式、行业；点击柱形、趋势点或环形分区查看对应校友；
- 校友地域地图：支持山东省与全国切换，点击区域会联动右侧行业与人员列表；
- 校友信息检索：按姓名、单位、职务、导师等关键词检索，点击条目查看完整信息；
- 地域与行业分布：省内外、城市、区县与行业联动查看。

## 9. 操作历史（管理员）

菜单“操作历史”查看管理员和校友本人对校友档案的操作记录。

筛选条件：日期范围、管理范围（本科生 / 学术学位研究生 / MPA专业学位研究生）、操作类型（新增 / 修改 / 删除 / 导入），可“清空筛选”。

列表字段为时间、操作人（含角色）、管理范围、校友档案（可跳转详情）、类型与“详情”。详情抽屉展示单次操作的内容：字段级变更的前后值、批量导入涉及的校友与字段、以及必要的处理说明。

也可以在“校友详情”页直接查看该校友的操作历史。审计信息不包含密码、无权限查看的敏感原值与文件预签名地址。

## 10. 管理员管理（超级管理员）

菜单“管理员管理”用于维护管理员账号。

- 列表字段：账号、姓名、可管理范围、敏感数据、档案文件、状态、操作；
- “新增管理员”：填写账号、姓名、手机号和初始密码；
- “编辑授权”：设置可管理范围（可多选培养类别）与功能权限（可查看敏感数据、可管理档案文件），保存后提示“管理员授权已更新”，下一次请求即生效；
- “删除”：删除管理员账号，需要二次确认；
- 角色为 `super_admin` 的账号显示“系统超级管理员”标签，不提供编辑授权与删除操作。

## 11. 常见问题

| 现象                         | 原因与处理                                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| 登录后看不到某个菜单         | 菜单按角色显示；管理员还需具备对应数据域或功能权限，请联系超级管理员确认授权                        |
| 列表里没有“工作单位”“职务”列 | 当前账号没有“可查看敏感数据”权限                                                                    |
| 详情页字段显示 `***`         | 同上，属敏感字段脱敏展示                                                                            |
| 上传档案文件失败             | 检查文件类型与大小（PDF、Word、JPG、PNG，单个不超过 50 MB）以及“可管理档案文件”权限                 |
| 导入失败或部分行失败         | 检查是否为 `.xlsx`/`.csv`、是否超过 20 MB 或 20000 行、姓名与年级是否填写、是否缺少“所属领域”或超出授权范围 |
| 院史投稿后正式词条没有变化   | 投稿需要管理员审核通过后才会写入正式词条                                                            |
| 忘记密码                     | 平台没有自助重置入口，请联系超级管理员                                                              |
