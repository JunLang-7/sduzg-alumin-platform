# 政管全球校友数字化平台和院史在线平台

面向山东大学政治学与公共管理学院校友：为管理员提供校友档案维护、校友查询与学院管理数据看板，为校友提供个人资料维护与院史资料共编。

## 主要能力

- **校友服务**：管理员按数据域查询校友目录与档案详情；校友在用户中心维护本人资料。登录支持账号密码及短信／邮箱验证码。
- **档案管理**：管理员维护校友档案数据，支持 Excel 导入导出与档案文件管理。
- **院史共编**：词条浏览、资料投稿、管理员审核与历史版本追溯。
- **管理与统计**：数据大屏、管理员授权、数据域与敏感字段控制、操作审计。

后端使用 Go、Gin、GORM，前端使用 React、TypeScript、Ant Design 与 ECharts；数据服务为 MySQL、Redis 和 Silo（MinIO 兼容），通过 Docker Compose 编排。

## 快速启动

安装 Docker 和 Docker Compose 后，在仓库根目录执行：

```bash
cp .env.example .env
docker compose up --build
```

启动后访问 [平台首页](http://127.0.0.1)。默认开发账号、服务端口、配置与升级方式见[部署说明](docs/deployment.md)。已有 `.env` 时保留现有配置；公开部署前需更换默认凭据并设置 JWT 密钥。
